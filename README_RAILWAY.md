# 🚂 دليل نشر التطبيق وفاحص الصفقات 24/7 على منصة Railway السحابية

هذا الدليل يشرح لك كيفية نشر التطبيق على منصة **Railway** السحابية ليعمل **24 ساعة يومياً طوال الأسبوع بدون توقف وبدون الحاجة لجهاز كمبيوتر أو سيرفر Windows VPS**.

---

## 🌟 لماذا Railway أفضل بكثير من Windows VPS؟
1. **استقرار فائق 100% سحابياً:** لا توجد تحديثات ويندوز إجبارية ولا انقطاعات في الاتصال أو شاشات RDP زرقاء.
2. **رابط ويب مباشر مع شهادة أمان SSL:** يمنحك Railway نطاقاً مجانياً آمناً (مثال: `https://your-app.up.railway.app`) يمكنك فتحه من هاتفك أو جهازك اللوحي لمتابعة التحليلات والصفقات في أي وقت.
3. **التحديث التلقائي:** بمجرد رفع أي تعديل على GitHub، يقوم Railway بإعادة بناء ونشر التطبيق تلقائياً دون أي تدخل يدوي منك.
4. **تشغيل مستمر لمحرك الفحص (24/7 Background Daemon):** فاحص الصفقات الخاطفة يعمل في الخلفية طوال الوقت، ويرسل الإشارات مباشرة إلى تليجرام ويزامن مع قاعدة بيانات Turso السحابية فوراً.

---

## 🚀 الطريقة الأولى: النشر المباشر عبر GitHub (الموصى بها - أسهل وأسرع طريقة)

### الخطوة 1: رفع المشروع على مستودع GitHub
1. في واجهة AI Studio، يمكنك تصدير المشروع إلى **GitHub** مباشرة عبر القائمة:
   - اضغط على زر **Settings / Export** أعلى الشاشة ➔ اختر **Export to GitHub**.
2. أو إذا كان لديك كود المشروع، قم بإنشاء مستودع جديد (Repository) على حسابك في GitHub وارفعه (عام Public أو خاص Private).

---

### الخطوة 2: فتح حساب على Railway وإنشاء المشروع
1. ادخل إلى الموقع الرسمي: [https://railway.app](https://railway.app)
2. سجّل الدخول بالضغط على **Login with GitHub**.
3. في لوحة التحكم (Dashboard)، اضغط على الزر الكبير **+ New Project**.
4. اختر **Deploy from GitHub repo**.
5. اختر مستودع المشروع الذي رفعته في الخطوة 1.
6. اضغط **Deploy Now**.

---

### الخطوة 3: ضبط المتغيرات السرية (Environment Variables)
1. داخل مشروعك على Railway، اضغط على اسم الخدمة (Service).
2. انتقل إلى تبويب **Variables** (المتغيرات).
3. اضغط **+ New Variable** أو **RAW Editor** وأضف المتغيرات التالية:

```env
NODE_ENV=production
PORT=3000
TELEGRAM_BOT_TOKEN=ضع_توكن_بوت_التليجرام_هنا
TELEGRAM_CHAT_ID=ضع_معرف_الدردشة_هنا
TURSO_DATABASE_URL=ضع_رابط_قاعدة_بيانات_تورسو_هنا
TURSO_AUTH_TOKEN=ضع_توكن_تورسو_هنا
```

*(إذا لم تكن تستخدم Turso أو Telegram حالياً، يمكنك تركها فارغة وسيعمل التطبيق أيضاً بشكل طبيعي).*

---

### الخطوة 4: تفعيل الرابط العام (Public Networking & Domain)
1. في نفس صفحة الخدمة على Railway، انتقل إلى تبويب **Settings**.
2. انزل إلى قسم **Networking**.
3. اضغط على زر **Generate Domain** لإنشاء رابط عام للتطبيق.
4. تأكد أن المنفذ (Port) مضبوط على **3000** (سيتعرف عليه Railway تلقائياً من ملف `Dockerfile`).
5. الآن أصبح لديك رابط سحابي مباشر مثل:
   `https://crypto-trade-analyzer-production.up.railway.app`

---

## 🛠️ الطريقة الثانية: النشر عبر Railway CLI (بدون GitHub)
إذا كنت تفضل رفع المشروع مباشرة من جهازك عبر سطر الأوامر:

1. ثبّت أداة Railway عالمياً عبر Node.js:
   ```bash
   npm install -g @railway/cli
   ```
2. سجّل الدخول بحسابك:
   ```bash
   railway login
   ```
3. داخل مجلد المشروع، اربط المشروع بـ Railway:
   ```bash
   railway init
   ```
4. ارفع وانشر المشروع بضغطة زر:
   ```bash
   railway up
   ```
5. افتح لوحة التحكم لإضافة المتغيرات وتوليد الرابط العام:
   ```bash
   railway open
   ```

## 📋 كيف تتأكد من عمل السيرفر وفاحص الصفقات 24/7؟
1. في لوحة تحكم Railway، اضغط على تبويب **View Logs** (أو Deploy Logs / Runtime Logs).
2. ستشاهد السجلات الحية لـ Express وفاحص الصفقات:
   ```text
   Server running on http://0.0.0.0:3000
   🚀 Background Scanner Daemon started (Interval: 60s, Mode: SCALP)
   🔍 [DAEMON] Starting background scan cycle #1...
   ```
3. عند رصد أي فرصة تداول مطابقة لقواعد جان ووايكوف ومربع التسعة، ستصلك رسالة فورية ومنسقة إلى تليجرام تلقائياً مع وسم:
   `🤖 فاحص السيرفر الدائم (24/7 Daemon)`

## 💡 معلومات تقنية حول بنية النشر المضافة للمشروع:
- **`Dockerfile`**: تم تجهيزه باستخدام صورة Node.js 20 Alpine خفيفة وسريعة، تقوم ببناء واجهة React ومخدم Express في ملف تنفيذي موحد `dist/server.cjs`.
- **`railway.json`**: ملف تكوين معتمد لمنصة Railway لضمان تفعيل سياسة إعادة التشغيل التلقائية (`ON_FAILURE`) في حال حدوث أي خطأ مفاجئ لضمان عمل الخدمة 24/7 دون انقطاع.
- **`.dockerignore`**: تم إعداده لتسريع عملية الرفع والبناء وتجنب نقل الملفات غير الضرورية.
